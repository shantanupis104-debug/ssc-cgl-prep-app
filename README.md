# SSC CGL Prep Pro (Android)

A native Android application built with Jetpack Compose and Kotlin, faithfully reproducing the official TCS iON CBT exam simulation and preparation suite for SSC CGL, Banking, and Railway aspirants.

## Features
- **Official TCS iON CBT Simulator**: Authentic exam environment with timer, section navigation, question palette with status coloring (Not Visited, Not Answered, Answered, Marked for Review), and bilingual switch (English / Hindi).
- **10-Year PYQ Vault (2015–2024)**: Access genuine past SSC CGL shift papers with cutoff benchmarks and CBT practice modes.
- **3-Bucket Error Diary**: Automated error categorization into Conceptual Gap, Silly Mistake, and Guesswork with spaced repetition review reminders.
- **Performance Analytics**: Real-time accuracy metrics, section score breakdowns, and time telemetry.
- **Subject Revision & Boosters Vault**: Formula sheets, high-yield concept cards, and quick drills across Reasoning, Quantitative Aptitude, English, and General Awareness.
- **Local Persistence**: Integrated Room Database storing student profiles, exam attempts, error diaries, and bookmarks offline.
